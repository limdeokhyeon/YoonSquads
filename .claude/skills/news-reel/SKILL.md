# 나우이슈 속보 릴스 제작

계정: **나우이슈 | 오늘의 이슈** (`@nowissue_today`). 사실 위주 · 출처 표기.

## 입력
사용자가 보내는 이미지 한 장(사진 + 제목 3줄 안팎 + 출처). 그 이미지의 **제목·태그·출처 문구를 그대로** 영상에 옮긴다. 사진은 글자가 시작되기 전 윗부분만 쓴다.

## 순서
1. **이미지 읽기**: 태그(속보/단독/정치 이슈), 제목 줄, 부제, 출처, 날짜를 옮겨 적는다.
2. **기사 확인** (WebSearch → WebFetch로 본문 2~3건):
   - 제목의 숫자·인용문·시각을 교차검증한다. 계산 가능한 수치(월 상환액 등)는 직접 계산해 확인한다.
   - 본문을 못 열거나 단독·의혹 보도라 확인이 안 되면 **그 사실을 사용자에게 알린다**. 확인 못 한 내용을 사실처럼 쓰지 않는다.
   - 사진 속 출처가 "제공된 기사 캡처"처럼 자리표시자면 실제 매체명으로 바꾼다.
3. **영상 생성**:
   ```
   python3 .claude/skills/news-reel/scripts/make_reel.py \
     --photo <입력이미지> --photo-bottom <글자 시작 직전 y> \
     --tag "속보" [--pre "합참 발표"] --lines "제목1" "제목2" "제목3" \
     [--post "보조문구1" "보조문구2"] --source "매체 | 2026.10.03." \
     --out reels/<이름>_10s.mp4 --preview /tmp/preview.png
   ```
   - `--photo-bottom`: 입력 이미지에서 빨간 태그가 시작되는 y보다 약간 위. 사진에 태그 일부가 남으면 값을 줄인다.
   - 미리보기 PNG를 **반드시 열어 확인**한다 (글자 잘림, 태그 폭, 사진 구도).
   - 글자는 y≈1520 아래로 내려가지 않게 한다 (인스타 하단 UI에 가림). 스크립트가 경고를 낸다.
   - 길이 기본 10초, 한 장면 고정(전환·팔로우 화면 없음). 사용자가 요청하면 `--seconds`로 조절.
4. **캡션 작성**: 아래 템플릿, 서술형. 확인한 사실만 쓴다.
5. **전달**: `SendUserFile`(display `render`)로 mp4를 보낸다. 이어서 `git add reels && git commit && git push -u origin claude/news-reel` (커밋 메시지 끝에 시스템이 알려준 attribution 줄 포함).
6. **답변 구성**: 영상 한두 줄 설명 → 기사 확인 내용 → 캡션(코드블록) → 확인해 달라는 점 → Sources 링크.

## 캡션 템플릿
```
[태그] 제목 한 줄

(리드 문단: 누가/언제/무엇을)

(세부 문단 1~2개: 숫자·인용·배경)

(의혹·수사·분석 중인 사안이면 "수사 중", "달라질 수 있습니다" 문장)

📰 출처: 매체 외 (YYYY.MM.DD.)

⚡ 오늘의 이슈가 궁금하다면?
👉 나우이슈 팔로우하고 실시간 소식 받아보세요!

#속보 #뉴스 #오늘의뉴스 #주제태그… #나우이슈   ← 10개 안쪽
```
- "※ 사진은 참고용 이미지입니다" 줄은 사용자가 뺐다. 기본은 넣지 않는다. 다만 사진이 사건 현장처럼 보이는 합성이면 한 번 짚어 준다.

## 지켜야 할 것
- **얼굴로 사람을 식별하지 않는다.** 이름은 제목·기사에 나온 것만 쓰고, 사진 속 인물이 누구인지 단정하지 않는다. 제목에 인물이 없는데 사진에 인물이 부각돼 오해 소지가 있으면 사용자에게 알린다.
- 의혹·단독·수사 중 사안은 단정형을 피하고 "의혹", "~로 전해졌습니다"를 쓴다.
- 부상자 수처럼 매체마다 다른 수치는 캡션에서 숫자를 빼거나 범위로 쓰고 그 사실을 알린다.
- 정치 사안은 발언 인용 위주로 중립하게 쓴다.
- 사용자가 사진 문구·로고·팔로우 화면을 빼라고 하면 그 선호를 이후 작업에도 유지한다.
- 키·토큰은 채팅에 받지 않는다.

## 디자인 수정은 피그마로 (사용자 지시)
- 영상·이미지의 **디자인을 고치거나 새로 꾸밀 때는 Figma 커넥터로 진행**한다 (`mcp__Figma__*`, 먼저 `ToolSearch`로 로드).
- 순서: `whoami`로 연결·플랜 확인 → `get_figma_skill`로 `skill://figma/figma-use/SKILL.md`를 읽고 → `create_new_file`(design, 1080x1920 프레임) → `use_figma`로 요소 작성·수정 → 스크린샷으로 확인.
- 단순히 문구·사진만 바꾸는 반복 제작은 기존대로 `make_reel.py`를 쓴다. 레이아웃·색·요소 같은 디자인 변경이 있으면 피그마를 쓴다.
- 피그마에서 내보낸 이미지는 mp4로 만들 때 ffmpeg(`-loop 1 -t 10`)로 변환한다.
- 연결이 안 되면 그 사실을 알리고, 캔바나 `make_reel.py`로 대신할지 묻는다.

## 참고
- 폰트(나눔고딕)는 스크립트가 처음 실행할 때 내려받는다 (`scripts/.fonts`, 커밋 안 함).
- 캔바로 꾸민 버전이 필요하면 Canva 커넥터 `create-design`(Instagram Story 1080x1920)으로 만들고 `export-design`(mp4 `vertical_1080p`, png)으로 내보낸다. 캔바 요소를 지운 자리에 그림자가 남으면 ffmpeg `delogo`로 지운다.
